# メモ帳

タイトルを選び、「量子検索」で本文を開くメモ帳です。グローバーの回路をブラウザ内でシミュレーションします。

## 起動

Node.js 22.13以降の22系、または対応する新しいLTSを使ってください。

```sh
npm ci
npm run dev
```

ターミナルに表示されるLocalのURLを開きます。通常は `http://127.0.0.1:5173/` です。

```sh
npm test
npm run build
npm run preview
```

ビルドは型検査を行い、`dist/` に静的ファイルを出力します。

## 使い方

- 一覧はタイトルのみを表示します。メモを選ぶと本文は伏せた状態になります。
- 「量子検索」1回で回路の計算と測定を行い、測定されたメモの本文を開きます。そのまま編集できます。
- 測定位置の初期値は最後です。変えたい場合だけ「回路と状態」を開き、スライダーを調整します。回路図と振幅・確率の表は一緒に表示します。
- 途中で測定すると、目標以外のメモや空き状態が出ることがあります。別のメモの場合は、そのメモを選択して本文を表示します。結果は成功で置き換えません。
- 観測後やメモの選択時には測定位置を最後に戻します。詳細欄は次の観測に使う回路と測定前の状態です。
- 本文欄は内容に応じて伸び、長い本文は欄の中でスクロールします。「量子検索」は画面上端に残るため、回路を見ながらそのまま押せます。
- 「新規」で作ったメモはすぐに書き込めます。「本文を伏せる」や他のメモの選択で本文を閉じられます。
- 削除直後は「元に戻す」で復元できます。タイトルの絞り込みとJSONへの書き出しに対応します。
- タイトルや本文の一部を選択してコピー（Ctrl+C、右クリックのコピーなど）をすると、選択範囲を量子テレポーテーションで転送し、受信した測定結果から復元した文字列をクリップボードへ書き込みます。「コピー完了」が表示されたら貼り付けられます。「コピーの詳細」を開くと回路と実際の測定結果を確認できます。追加の実行ボタンはありません。

メモ本文はlocalStorageに自動保存します。サーバーやGitHubには送信しません。GitHubに保存するのはプログラムです。保存形式とキーは以前の版と同じで、既存のメモを引き継ぎます。ブラウザとオリジン（ホスト・ポート）が違うと保存領域も異なります。ブラウザのデータを削除する前に、必要なメモをJSONに書き出してください。

## 量子計算

計算部分は画面から独立した `src/quantum/simulator.ts` にあります。Qiskitや量子実機は使用していません。

1. メモ数Nに対して `ceil(log2(N))` 量子ビットを用意します。
2. 実部・虚部を持つ状態ベクトルにHゲートを適用し、一様な重ね合わせを作ります。
3. 選んだメモの番号を印付けするオラクルと拡散回路を、H・X・多重制御Xで構成します。
4. 指定した位置までのゲートを適用した状態の確率から、1回だけ測定します。初期値の最後まで進めると、最初の成功確率の山に達します。

拡散回路は標準の演算子の負号付きです。グローバル位相を状態ベクトルに保持します。確率は複素振幅の絶対値の2乗です。途中状態の参照は測定ではなく、測定は「量子検索」を押したときに行います。測定には `crypto.getRandomValues` の古典的な乱数を使います。

| メモ数 | 基底状態数 | 最後までの増幅回数 | 目標の測定確率 |
| --- | --- | --- | --- |
| 1 | 1 | 0 | 100%（量子ビット不要） |
| 2 | 2 | 0 | 50% |
| 3〜4 | 4 | 1 | 100% |
| 5〜8 | 8 | 2 | 約94.53% |
| 9〜16 | 16 | 3 | 約96.13% |

候補数は次の2のべき乗に切り上げ、余った基底状態は空き状態として扱います。初期版は最大16件です。シミュレーションによる検索の高速化は目的としていません。

## コピーの量子テレポーテーション

コピーイベントの既定処理を止め、インラインのWeb Worker内で選択範囲の全ビットを転送します。転送が完了するまでクリップボードには書き込みません。受信側の測定結果から復元した文字列をAsync Clipboard APIで書き込み、書き込み成功後に「コピー完了」を表示します。先に元の選択範囲をコピーすることも、エラー時に元の文字列で代用することもありません。

処理中は「コピー中」と進捗を表示します。長い選択範囲でも編集を止めず、再コピー・メモの切り替え・本文の非表示で未完了の転送を中止します。書き込みが許可されない場合はコピー失敗を表示します。Async Clipboard APIがない環境では、コピーイベント内で同期的に全ビットを計算し、その測定結果をイベントのクリップボードへ設定します。

文字列をUTF-16の16ビット単位に分け、各ビットに新しい3量子ビットを用意します。q0に入力ビットを準備し、q1へのHとq1→q2のCNOTでもつれを作ります。q0→q1のCNOT、q0へのH、q0・q1の部分測定を実際に状態ベクトル上で計算します。測定値m1に応じてq2へX、m0に応じてZを適用し、q2の測定結果から文字列を再構成します。既知のビットを転送する用途ですが、実装は複素振幅を持つ任意の1量子ビット状態にも対応し、テストで位相の復元も検証します。

詳細は直近のコピーの実行記録です。ビット番号を選ぶと、そのビットの入力、実際のm0・m1、適用した補正、受信結果を同じ回路上で表示します。全ビットについて4通りの途中測定の回数も表示します。詳細を開き直したりビット番号を変えても再測定はしません。別のメモの選択・本文の非表示・ページの再読み込みで記録を消し、保存データやサーバーへ送信しません。

量子実機・量子通信は使わず、測定の抽選にはブラウザの暗号学的乱数を使います。

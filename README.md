# Quantum Notes

静かなメモ帳と、少し無駄な量子検索。

一覧で選んだメモを、グローバーのアルゴリズムでもう一度探します。検索対象はすでにわかっていますが、その番号を印付けするオラクルを生成し、量子回路を実際にシミュレーションして測定結果を返します。

## 起動

Node.js 22.13以降の22系、または対応する新しいLTSを使用してください。

```sh
npm ci
npm run dev
```

ターミナルに表示される `http://127.0.0.1:5173/` を開きます。ポート使用中はViteが別のポートを表示します。

```sh
npm test
npm run build
npm run preview
```

`npm run build` は型検査と本番用ビルドを行い、`dist/` に静的ファイルを出力します。

## 初期版の機能

- 最大16件のメモ作成・編集・削除・削除直後の取り消し
- タイトルと本文による通常の絞り込み
- 「伏せて探す」モード：タイトル・本文を隠し、保存順を変えずにカードをシャッフル
- 任意のゲート位置で測定して、その測定結果のメモ1枚だけを開封
- このブラウザのlocalStorageへの自動保存、JSONへの書き出し
- グローバー検索の状態ベクトルシミュレーション
- 実行したゲートの再生、一時停止、1操作送り、スライダーでの移動
- SVG回路図と、各操作直後の複素振幅・確率の表示
- キーボード操作、狭い画面用のレイアウト

メモ本文はサーバーやGitHubへ送信しません。GitHubに保存するのはプログラムです。メモはブラウザとオリジン（ホスト・ポート）ごとに別の保存領域になります。ブラウザのデータを消すと失われるので、必要に応じてJSONを書き出してください。読み込めない保存データをサンプルで上書きすることはありません。

## シミュレーションの内容

計算部分はReactから独立した `src/quantum/simulator.ts` にあります。Qiskitや量子実機は使用していません。

1. メモ数 `N` に対して `n = ceil(log2(N))` 量子ビットを用意します。
2. `2^n` 個の基底状態を、実部と虚部を持つ `Float64Array` で表現します。q0が最下位ビットです。
3. 各量子ビットへのHゲートで一様な重ね合わせを作ります。
4. 目標番号の0ビットにXを適用し、H・多重制御X・Hで目標の位相を反転し、Xを戻します。
5. H・X・多重制御Xによる拡散操作で振幅を増幅します。
6. 最初の成功確率の山にある整数の反復回数を選び、4〜5を繰り返します。
7. 計算した振幅の絶対値の2乗に従って測定し、対応するメモを返します。

拡散回路は標準的な拡散演算子の負号付き（グローバル位相の違い）です。位相は状態ベクトルにそのまま保持します。単一ゲートのH・X・Z・S、および多重制御Xを計算でき、全操作後の状態を記録します。

測定は `crypto.getRandomValues` の古典的な乱数によるサンプリングです。量子乱数を生成しているわけではありません。目標以外が出たとき、目標で置き換えることはありません。数値表示の「目標の測定確率」は測定直前の分布で、測定後の確定状態とは区別します。

### 候補数と成功確率

| メモ数 | 基底状態数 | 増幅回数 | 目標の測定確率 |
| --- | --- | --- | --- |
| 1 | 1 | 0 | 100%（量子ビット不要） |
| 2 | 2 | 0 | 50% |
| 3〜4 | 4 | 1 | 100% |
| 5〜8 | 8 | 2 | 約94.53% |
| 9〜16 | 16 | 3 | 約96.13% |

2のべき乗に満たない分は空き状態です。空き状態が測定された場合も、その結果をそのまま表示します。通常の絞り込みに関係なく、全メモを候補とします。

実際の回路の計算はすぐ完了します。「操作を再生」は、記録済みの状態をゆっくり見返すためのものです。再生による待ち時間は計算時間に含めず、測定も再抽選しません。新しく測定するには「量子検索」をもう一度押します。

### 伏せたメモの開封

1. 「伏せて探す」に切り替えると、メモのIDだけをシャッフルしてメモA〜Pとして表示します。保存済みの並び順・本文は変えません。
2. カードを選び「量子検索」を押すと、測定前の回路と全操作の状態を計算します。この時点で測定結果の抽選は行いません。最初に表示するのは、Hゲートで一様な重ね合わせを作った直後です。
3. 操作送り・再生・スライダーで位置を選び、「この位置で測定して開封」を押すと、その状態の確率で1回だけ測定します。そこから先のゲートは破棄し、計算を終了します。
4. 測定されたメモ1枚だけのタイトル・本文が表示されます。目標以外や空き状態も、そのまま返します。測定後の履歴再生では再抽選しません。

回路図・振幅表・結果欄には本当のタイトルを渡さず、A〜Pの記号で統一します。通常の絞り込みとJSON出力は伏せたモードでは使いません。「メモを書く」に戻ると普通に編集できます。「このメモを編集」は、開封したメモを選択して通常モードへ戻ります。

これは見え方を変える遊びで、暗号化やアクセス制御ではありません。ブラウザ内には元のメモを保存しています。途中状態の表示は古典シミュレーターのデータ参照で、量子測定とは区別します。

## 検証

Vitestで、全対応件数・全目標について解析式の成功確率と照合しています。各操作後の規格化、複素位相、制御ゲート、測定後の再測定、失敗時と空き状態の結果、途中測定による成功確率の変化、保存データ、伏せた表示からの情報漏れも検証します。

GitHub Actionsで `npm ci`・`npm test`・`npm run build` を実行します。
